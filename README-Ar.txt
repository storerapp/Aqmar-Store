نسخة ثابتة جاهزة لـ GitHub Pages
================================================

محتويات الملف:
- index.html            الصفحة العربية الرئيسية
- en/index.html         الصفحة الإنجليزية
- css/                  ملفات التصميم
- js/                   القائمة والموسيقى والحركات
- assets/               الفيديو والموسيقى وصور الأفلام
- .nojekyll             لضمان عرض الملفات مباشرة على GitHub Pages

طريقة الرفع على GitHub:
1) فك ضغط الملف.
2) ارفع جميع المحتويات إلى جذر المستودع (يجب أن يبقى index.html في الجذر).
3) افتح Settings ثم Pages.
4) اختر Deploy from a branch، ثم main و /(root)، واضغط Save.

لا يحتاج الموقع إلى npm أو عملية build أو أي إضافات.
